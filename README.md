# Current Year

A first-person 3D life sim set in a small rural Oregon town. You're 24, your parents just kicked you out, and you need a job. Nobody is hiring.

Open `index.html` in a browser to play. It's a single self-contained file (three.js loads from cdnjs).

Design notes are in `design.md`.
